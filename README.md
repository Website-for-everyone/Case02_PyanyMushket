# 🍗 Пьяный Мушкет — Таверна 16 Века в Вебе (Case 02)

«Пьяный Мушкет» — атмосферный веб-проект, воссоздающий средневековый трактир XVI века со скевоморфизмом состаренного пергамента, звуками очага и лютни, королевской доской розыска и колоритным Telegram-ботом-трактирщиком.

---

## 🛡 Особенности проекта

### 1. Веб-интерфейс (16th-Century Skeuomorphism)
- **Состаренный пергамент:** Текстуры манускрипта с обожженными краями, готическими буквицами и старинными гравюрами из открытых архивов.
- **Гусиное перо и чернила:** Интерактивный курсор-перо оставляет реалистичные чернильные кляксы при кликах по пергаменту.
- **Web Audio Атмосфера:** Встроенный аудио-плеер с процедурным потрескиванием огня в камине и акустической средневековой лютней.
- **Старинная валюта:** Все яства и хмельные напитки оценены в дукатах, грошах и талерах с подсказкой курса в рублях.
- **Доска королевского розыска:** Интерактивные листовки с наградами за поимку разбойников и похвальные грамоты короны.
- **3D-книга меню:** Перелистывание страниц фолианта с анимацией переворачивания листов.

### 2. Telegram-бот Трактирщик (Aiogram 3.x)
- **Старорусский слог:** Аутентичный говор трактирщика («Здрав будь, боярин! Чего изволишь отведать?»).
- **Инлайн-бронь столов:** Выбор дубового стола: `[ У камина ]`, `[ Под королевским штандартом ]`, `[ В винном погребе ]`.
- **Генератор сургучной грамоты:** Автоматическое создание гербовой грамоты с сургучной печатью о подтверждении бронирования.
- **Сквозной канал:** Заявки поступают администратору и дублируются на аккаунт владельца `@Idrisov_prod`.

## 🚀 Запуск и тестирование

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-трактира
```bash
python web/app.py
# Откройте: http://localhost:8002
```

### 3. Запуск бота-трактирщика
```bash
python bot/bot.py
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
