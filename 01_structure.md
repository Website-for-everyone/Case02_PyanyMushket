# АРХИТЕКТУРА И СПЕЦИФИКАЦИЯ: ПЬЯНЫЙ МУШКЕТ

> **Проект:** Пьяный Мушкет (Case 02)  
> **Клиент / Заказчик:** Историческая иммерсивная таверна «Пьяный Мушкет»  
> **Чек проекта:** 165 000 ₽ | **Срок:** 16 дней (Дедлайн: 2026-11-27)  
> **Дедлайн MVP (80%):** 2026-11-23  
> **Тип договора:** Договор СМЗ с ИП (Чек «Мой Налог», 6%)

---

## 🛠 Технологический стек
- **Frontend / UI:** Skeuomorphic Parchment SPA, HTML5 Canvas / Web Audio API (акустическая лютня и треск очага), CSS 3D Transforms (перелистывание меню), кастомный курсор-перо с чернильными каплями
- **Backend & Logic:** Python 3.12, FastAPI, Uvicorn, Pillow (генерация сургучных грамот)
- **Telegram Bot:** Aiogram 3.31 (Трактирщик на старорусском языке, бронь дубовых столов, выдача сургучных грамот)
- **База данных & Хранилище:** SQLite (книга броней трактира)
- **Уведомления:** Пересылка броней столиков в Telegram-аккаунт `@Idrisov_prod`

---

## 🎨 Дизайн-система (16th Century Burnt Parchment)
- **Палитра:**
  - Состаренный пергамент: `#E2D1B3`
  - Обожженные края: `#3E2718`
  - Темный дуб и хмельной эль: `#1F140E`
  - Сургучный красный: `#8B1E1E`
  - Королевская латунь и злато: `#C89B3C`
- **Типографика:** Готическая каллиграфия, буквицы (Drop-caps), винтажные засечки Cormorant Garamond.
- **Интерактивные элементы:**
  - Перо-курсор с разлетающимися чернильными брызгами.
  - Процедурный синтез потрескивания углей очага и лютни.
  - Цены в дукатах, грошах и талерах с конвертером в рубли.
  - Доска королевского розыска с сорванными пергаментными указами.

## 🏛 Архитектурная схема
```
[ Посетитель таверны ] ───► [ Лютня & Очаг / Меню-фолиант / Доска розыска ]
          │
          ▼
[ Бронь дубового стола ] ──► [ FastAPI /api/tavern/reserve ] ──┐
                                                               │
[ Гость в Telegram ] ─────► [ Бот-Трактирщик (Aiogram 3) ] ────┼──► [ SQLite DB ]
                                                               │
                                                               ├──► [ Сургучная грамота PNG/SVG ]
                                                               └──► [ Уведомление @Idrisov_prod ]
```
